TEST SCENARIOS (4 files)
================================================================================

1. scenarios/01-baseline-50-users.js
   ├─ Virtual Users: 50
   ├─ Duration: 5 minutes
   ├─ Purpose: Establish baseline performance
   ├─ Endpoints: /api/student/quiz/submit-answer + /api/quiz-grade
   ├─ Target: p99 < 500ms, 0% error
   └─ Expected: All requests succeed without degradation

2. scenarios/02-stress-100-users.js
   ├─ Virtual Users: 100
   ├─ Duration: 5 minutes
   ├─ Purpose: Identify degradation at 2x baseline load
   ├─ Target: p99 < 2s, < 1% error
   └─ Expected: Noticeable slowdown but acceptable performance

3. scenarios/03-spike-500-users.js
   ├─ Virtual Users: 500
   ├─ Duration: 2 minutes
   ├─ Purpose: Test graceful degradation at 10x baseline
   ├─ Target: p99 < 5s, < 5% error, no 503s
   └─ Expected: Rate limiting kicks in, system stable

4. scenarios/04-sustained-grade-endpoint.js
   ├─ Virtual Users: 50
   ├─ Duration: 10 minutes
   ├─ Purpose: Test rate limiting (10 req/min per IP)
   ├─ Target: p99 < 1s, rate limiting enforced
   └─ Expected: 429 responses with Retry-After headers

5. scenarios/helpers.js
   ├─ CSRF token generation/handling
   ├─ JWT token creation for testing
   ├─ API header setup
   ├─ Test data generation
   ├─ Error logging utilities
   └─ Shared test utilities

ENDPOINTS UNDER TEST
================================================================================

1. POST /api/student/quiz/submit-answer
   ├─ Simulates: Student submitting quiz answer
   ├─ Expected latency: 20-150ms (database insert)
   ├─ Database operation: INSERT into quiz_responses table
   ├─ Rate limit: None (no limit on answer submissions)
   └─ Tested in: All 4 scenarios

2. POST /api/quiz-grade
   ├─ Simulates: Answer grading with Claude AI
   ├─ Expected latency: 500-3000ms (Claude API latency)
   ├─ API call: Anthropic Claude API for essay/code grading
   ├─ Rate limit: 10 requests/min per IP
   ├─ Cost impact: ~$0.003 per request (Haiku model)
   └─ Tested in: All 4 scenarios

================================================================================
METRICS COLLECTED
================================================================================

Standard HTTP Metrics:
  - http_req_duration (p50, p95, p99, max)
  - http_req_failed (count, rate)
  - http_reqs (total, rate per second)
  - http_req_blocked, http_req_connecting
  - http_req_waiting, http_req_receiving
  - data_received, data_sent

Custom Metrics:
  - submit_answer_duration (quiz response insertion)
  - quiz_grade_duration (Claude AI grading time)
  - submitAnswerErrors (failed submissions)
  - gradeErrors (failed grades)
  - rateLimitHits (429 responses)
  - successfulGrades (completed grades)

Derived Metrics:
  - iteration_duration (complete test cycle)
  - group_duration (request group timing)
  - check pass rate (assertion success)
  - threshold pass/fail status

QUICK START COMMANDS
================================================================================

# Start mock server (for demo/testing without app)
node mock-server.js

# Run baseline test against mock server
BASE_URL=http://localhost:3000 k6 run scenarios/01-baseline-50-users.js

# Run baseline test against real app
BASE_URL=http://localhost:3002 k6 run scenarios/01-baseline-50-users.js

# Run baseline test against production
BASE_URL=https://api.dailyagile.com k6 run scenarios/01-baseline-50-users.js

# Run all scenarios with results export
./run-all-tests.sh

# Export to CSV for analysis
k6 run scenarios/01-baseline-50-users.js --out csv=results/baseline.csv

# Export to JSON summary
k6 run scenarios/01-baseline-50-users.js --summary-export=results/summary.json
