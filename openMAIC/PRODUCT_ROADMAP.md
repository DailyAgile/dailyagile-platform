# DailyAgile Academy — Product Roadmap

**Vision:** Build the world's leading platform for learning AI + Agile skills through multiple modalities (ILT, Self-Paced, Quizzes)

**Timeline:** August 2026 – December 2026 (and beyond)

---

### **Phase 1: Academy Dashboard Launch** (Aug 18–31, 2026)
**Goal:** Launch central hub connecting all three products

#### Deliverables
- ✅ `/academy` main dashboard (built)
- ✅ Quiz testing suite: 46/46 passing (ready)
- ✅ Navigation routing (built)
- ✅ User authentication & role detection (ready)
- ⏳ Live deployment to production
- ⏳ User acceptance testing (UAT)

#### Success Criteria
- Dashboard loads in <2s
- 95% uptime on day 1
- All 3 product cards navigate correctly
- User authentication works for instructors & students

### **Phase 2: Self-Paced Launch** (Sep 1–30, 2026)
**Goal:** Launch first 3 self-paced subjects on OpenMAIC

#### Subjects to Launch
1. **AI for Business Professionals** — £49–£299
   - Modules: AI Basics, ML Fundamentals, GenAI, Prompt Eng, Agents, Ethics
   - Duration: 12–20 hours
   - Content source: Microsoft AI-For-Beginners (adapted)
   - Embedded quizzes: 3 per module

2. **AI Engineer Course** — £399–£599
   - Modules: Foundations, Neural Nets, Computer Vision, NLP, RAG, Agents, MLOps, Agile
   - Duration: 40–60 hours
   - Content source: Microsoft AI-For-Beginners + new labs
   - Labs: 3 (Python notebooks, code challenges)

3. **MLOps/Operations** — £299–£499
   - Modules: Containerization, Kubernetes, CI/CD, Monitoring, Cloud Services, AIOps
   - Duration: 20–30 hours
   - Content source: Custom + cloud provider docs
   - Labs: 2 (Docker, Kubernetes hands-on)

#### Deliverables
- ✅ Subject listing page (built)
- ⏳ Content upload & organization system
- ⏳ Enrollment workflow
- ⏳ Payment integration (Stripe)
- ⏳ Progress tracking dashboard
- ⏳ Certificate generation

#### Success Criteria
- 3 subjects live and enrollable
- 100 students enrolled across all subjects
- >70% course completion rate
- >75% quiz pass rate
- Stripe payments processing successfully
