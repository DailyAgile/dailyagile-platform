## PRODUCTION WORKFLOW (for Video Agent)

1. **Create Remotion composition** for each video (3 separate files)
   - `/dailyagile-videos/src/compositions/Quiz_Create.tsx`
   - `/dailyagile-videos/src/compositions/Quiz_Take.tsx`
   - `/dailyagile-videos/src/compositions/Quiz_Extension.tsx`

2. **Render each to MP4**
   ```bash
   npx remotion render src/compositions/Quiz_Create.tsx QuizCreateComp out/quiz-create.mp4 --width 1920 --height 1080 --fps 30
   npx remotion render src/compositions/Quiz_Take.tsx QuizTakeComp out/quiz-take.mp4
   npx remotion render src/compositions/Quiz_Extension.tsx QuizExtensionComp out/quiz-extension.mp4
   ```

3. **Add voiceover & music**
   - Record voiceover in quiet room (44.1kHz, stereo)
   - Mix with background music (-6dB reduction during speech)
   - Use FFmpeg to combine: `ffmpeg -i video.mp4 -i audio.wav -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 final.mp4`

4. **Upload to YouTube**
   - Channel: DailyAgile (learners@dailyagile.com)
   - Visibility: Unlisted (accessible via link, not in search)
   - Captions: Auto-generate, then manually review + edit
   - Thumbnails: Consistent branding (navy bg, white text, orange accent)

5. **Embed in help pages**
   - `/openMAIC/public/help/create-quiz.html` — embed Video 1
   - `/openMAIC/public/help/take-quiz.html` — embed Video 2
   - `/openMAIC/public/help/request-extension.html` — embed Video 3
