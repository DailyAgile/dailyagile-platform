## 🎤 Interview Guide (For Qualitative Depth)

**When to Use:** If you have time during session (not required for all participants)

**Duration:** 3-5 min for key follow-ups

### Teacher Interview (Optional Depth Questions)

```
1. Tell me about your typical classroom workflow today.
   → Listen for: How many students? What tools do they use? Pain points?

2. What's your biggest challenge with managing student information?
   → Listen for: Spreadsheet chaos? Missed updates? Time-consuming?

3. How does this compare to tools you've used before?
   → Listen for: Competitive comparison, feature gaps, "wow this is better"

4. If you could wave a magic wand, what would the perfect tool do?
   → Listen for: Dream features, future roadmap signals

5. When would you first use this? Next week? Next semester?
   → Listen for: Adoption timeline, urgency, adoption blockers
```

### Student Interview (Optional Depth Questions)

```
1. Tell me how you usually study for quizzes.
   → Listen for: Memorization? Practice? Group study? Real learning?

2. How did this quiz experience feel different from others you've taken?
   → Listen for: More/less stressful? Clearer? Confusing?

3. Did the feedback on your answers help you understand why you were wrong?
   → Listen for: Learning effectiveness, feedback quality, confidence

4. What would make you more likely to actually study for quizzes?
   → Listen for: Motivation, engagement levers, feature requests

5. Is there anything that would make you dread quizzes less?
   → Listen for: Anxiety reduction, UX improvements, features
```
