## 🔗 File Dependencies & Data Flow

### Adding a Student (Complete Flow)

```
User clicks "Add Student"
        ↓
StudentRosterForm.tsx (UI)
        ↓
POST /api/classrooms/[id]/students
        ↓
route.ts (validation + auth)
        ↓
addStudentToClassroom() [lib/ilt/db/students.ts]
        ├─ Check classroom ownership
        ├─ Create or find student
        ├─ Create roster entry
        └─ Log audit event
        ↓
Database (supabase/migrations/001_...)
        ├─ INSERT students table
        ├─ INSERT student_rosters table
        ├─ Trigger: update_rosters_updated_at
        └─ INSERT audit_logs table
        ↓
Response to client
        ↓
StudentRosterForm.tsx shows success
        ↓
StudentRosterTable.tsx refetches data
```

## 📝 Database Schema Reference

### Key Tables

#### `classrooms`
```sql
id, stage_id, title, instructor_id, access_code, is_active, settings, created_at, updated_at
```
**RLS:** Instructor can manage; students can view if enrolled

#### `students`
```sql
id, email, name, student_id, avatar_url, created_at, updated_at
```
**RLS:** Users see own; instructors see their class students

#### `student_rosters` (Junction Table)
```sql
id, classroom_id, student_id, role, enrollment_date, status, metadata, created_at, updated_at
```
**RLS:** Instructor manages; students view own  
**Status:** active | dropped | unenrolled (soft delete via status)

#### `quiz_submissions`
```sql
id, classroom_id, student_id, scene_id, quiz_id, submitted_at, completed_at,
score, max_score, percentage, status, metadata, created_at, updated_at
```
**RLS:** Student sees own; instructor sees class  
**Status:** in_progress | submitted | graded

#### `quiz_answers`
```sql
id, submission_id, question_id, question_text, user_answer, correct_answer,
is_correct, points_earned, max_points, feedback, question_type, created_at
```
**RLS:** Inherits from quiz_submissions

#### `instructor_sessions`
```sql
id, classroom_id, instructor_id, session_start, session_end, session_type,
quiz_being_monitored, student_visibility, is_quiz_locked, metadata, created_at, updated_at
```
**RLS:** Only instructor sees their sessions

#### `quiz_questions`
```sql
id, quiz_id, question_number, question_text, question_type, difficulty,
points_max, options (JSON), correct_answer, explanation, created_at
```
**RLS:** Instructors see all; students see only active quizzes  
**Question Types:** multiple_choice | short_answer | true_false | essay

#### `quiz_submissions`
```sql
id, classroom_id, student_id, quiz_id, status, score, max_score, percentage,
submitted_at, graded_at, time_spent_seconds, metadata, created_at, updated_at
```
**RLS:** Student sees own; instructor sees class submissions  
**Status Flow:** in_progress → submitted → graded  
**Time Window:** Submission expires 30 minutes after start (configurable)

#### `quiz_answers`
```sql
id, submission_id, question_id, question_text, student_answer, correct_answer,
is_correct, points_earned, max_points, feedback, question_type, created_at
```
**RLS:** Inherits from quiz_submissions via submission_id  
**Feedback:** Generated by Claude API during grading

#### `quiz_submission_status_history`
```sql
id, submission_id, old_status, new_status, changed_by, reason, created_at
```
**RLS:** Instructor sees classroom changes; students see own  
**Purpose:** Audit trail for submission state transitions

#### `audit_logs`
```sql
id, classroom_id, actor_id, action, resource_type, resource_id, details, created_at
```
**RLS:** Instructor sees classroom logs; users see own access  
**Purpose:** GDPR compliance, debugging, audit trail

## 🚀 API Endpoints Reference

### Student Roster Management

**GET** `/api/classrooms/:classroomId/students`
```bash
# List students with filters
curl "http://localhost:3000/api/classrooms/abc-123/students?status=active&page=1&limit=50&search=alice" \
  -H "Authorization: Bearer $TOKEN"

# Response
{
  "students": [
    {
      "id": "...",
      "student": { "id", "email", "name", "student_id", ... },
      "enrollment_date": "2026-08-01T...",
      "status": "active",
      ...
    }
  ],
  "pagination": { "page": 1, "limit": 50, "total": 150, "total_pages": 3 }
}
```

**POST** `/api/classrooms/:classroomId/students`
```bash
curl -X POST "http://localhost:3000/api/classrooms/abc-123/students" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alice@example.com",
    "name": "Alice Johnson",
    "student_id": "STU-001"
  }'

# Response (201)
{
  "student": { ... },
  "roster": { ... },
  "invitation_sent": false
}
```

**PATCH** `/api/classrooms/:classroomId/students?student_id=:studentId`
```bash
curl -X PATCH "http://localhost:3000/api/classrooms/abc-123/students?student_id=def-456" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "status": "dropped" }'

# Response (200)
{ id, classroom_id, student_id, status: "dropped", ... }
```

**DELETE** `/api/classrooms/:classroomId/students?student_id=:studentId`
```bash
curl -X DELETE "http://localhost:3000/api/classrooms/abc-123/students?student_id=def-456" \
  -H "Authorization: Bearer $TOKEN"

# Response (200)
{ "success": true }
```

## 🐛 Common Issues & Solutions

### "Permission denied" Error
**Cause:** RLS policy blocking access  
**Check:** Verify instructor owns classroom or student is enrolled  
**Debug:** Check audit_logs to see what was attempted

### Student not showing in roster
**Cause:** Status is 'dropped' or 'unenrolled', not 'active'  
**Check:** Verify filter in UI (should show 'all' to see dropped students)

### Slow roster loading
**Cause:** Missing index or N+1 query problem  
**Check:** Verify indexes exist on (classroom_id, status)

### Audit logs not appearing
**Cause:** Logging middleware not running  
**Check:** Verify audit_log() function is called after mutations
