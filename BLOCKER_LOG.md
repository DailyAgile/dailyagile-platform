---

## Blocker Categories

Track by type for retrospective analysis:

- **Dependency Blockers** — Agent waiting on another agent's work
- **Technical Blockers** — Bug, tooling issue, environment problem
- **Clarity Blockers** — Specification unclear, UX decision needed
- **Resource Blockers** — Not enough time/people to complete work
- **External Blockers** — Third-party service down, API not working, etc.

---

## Blocker Workflow

1. **Report** — Agent posts blocker in daily standup (or immediately if critical)
2. **Investigate** — Coord Agent reaches out to blocking agent same day
3. **Escalate** — If unresolved after 4 hours, escalate to Product Owner
4. **Resolve** — Document resolution + time-to-resolve
5. **Log** — Add to this file for retrospective
