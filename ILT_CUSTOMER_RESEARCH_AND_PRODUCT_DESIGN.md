## 🎯 CUSTOMER RESEARCH: What PMP Buyers Need

### Methodology
Persona: Sarah Chen, Project Manager at TechCorp  
Goal: Purchase PMP Boot Camp to pass PMP exam within 90 days  
Budget: £400-500  
Risk: Can't afford another failed attempt at exam

### What Sarah MUST See to Buy

#### 1. **Course Description** (Trust Building)
*Why:* "Will this course help me pass the PMP exam?"

**What to show:**
- 1-2 sentence headline: "PMP Boot Camp: Industry-leading prep for PMBOK 6th Edition"
- Paragraph description (150 words): Overview of what the course covers
- Learning path diagram: "Week 1 → Week 2 → Week 3 → Week 4 → Exam Ready"
- Student testimonial: "Passed on first attempt" (social proof)

**Example copy:**
> "Pass your PMP exam on the first attempt with our proven 4-week intensive boot camp. Our instructors have guided over 2,400 project managers to certification with a 95% first-attempt pass rate. You'll master PMBOK processes, practice with 500+ exam-style questions, and take 3 full-length mock exams."

---

#### 2. **Learning Objectives** (Clarity)
*Why:* "Will I actually learn what I need?"

**What to show:**
- 5-8 specific, measurable objectives (NOT generic)
- Format: "By the end, you'll be able to..."

**Template:**
```
✓ Master all 49 PMBOK processes across 5 knowledge areas
✓ Answer 80% of exam-style questions correctly (passing threshold)
✓ Explain integration, scope, schedule, cost, quality, resource, 
  communication, risk, and procurement management
✓ Apply real-world scenarios to PMP situations
✓ Score 700+ on mock exams (equivalent to PMP exam)
✓ Understand the PMBOK 6th Edition updates & rule changes
```

---

#### 3. **Prerequisites** (Honesty)
*Why:* "Do I qualify for this course?"

**What to show:**
- What you NEED to know before starting
- What you DON'T need (removes fear)
- Time commitment required

**Template:**
```
Prerequisites:
✓ 3+ years project management experience (PMP requirement)
✓ Familiarity with project management fundamentals
✗ No programming or technical skills needed
✗ No prior certification required

Time Commitment:
• Live sessions: Tuesday & Thursday, 6-8 PM GMT (4 hours/week)
• Self-study: 10-15 hours/week recommended
• Total: 14-19 hours/week for 4 weeks
• Flexible: Recordings available for 6 months
```

## 📊 DATABASE SCHEMA FOR ILT COURSES

### Table 1: `ilt_courses` (Master Course Data)
```sql
CREATE TABLE ilt_courses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- Basic Info
  name TEXT NOT NULL,              -- "PMP Boot Camp"
  slug TEXT UNIQUE NOT NULL,        -- "pmp-boot-camp" (URL safe)
  description TEXT NOT NULL,        -- Full course description (150+ words)
  short_description TEXT,           -- 1-2 sentences for listings
  
  -- Instructor Info
  instructor_id UUID REFERENCES instructors(id),
  instructor_name TEXT,             -- Denormalized for faster queries
  instructor_credentials TEXT,      -- "PMP, 15+ years"
  instructor_pass_rate NUMERIC,     -- 94%
  
  -- Course Details
  duration_weeks INTEGER,           -- 4
  total_hours INTEGER,              -- 32 (8 hours/week)
  difficulty_level TEXT,            -- 'beginner' | 'intermediate' | 'advanced'
  
  -- Learning Information
  learning_objectives JSONB,        -- Array of 8 objectives
  prerequisites JSONB,              -- {"required": [...], "optional": [...]}
  syllabus JSONB,                   -- {"week1": {...}, "week2": {...}, ...}
  
  -- What's Included
  included_items JSONB,             -- {
                                    --   "live_sessions": 8,
                                    --   "practice_questions": 500,
                                    --   "mock_exams": 3,
                                    --   "exam_voucher": "£350",
                                    --   ...
                                    -- }
  
  -- Post-Course
  post_course_info JSONB,           -- {
                                    --   "if_pass": {...},
                                    --   "if_fail": {...},
                                    --   "guarantees": {...}
                                    -- }
  
  -- Pricing
  price_gbp NUMERIC NOT NULL,       -- 399.00
  price_usd NUMERIC,                -- For US customers
  payment_plans JSONB,              -- [
                                    --   {"installments": 3, "amount": 150}
                                    -- ]
  discount_percent INTEGER,         -- 50 (50% discount for launch)
  
  -- Meta
  category TEXT,                    -- 'certification' | 'professional-dev'
  tags JSONB DEFAULT '[]'::jsonb,   -- ["PMP", "PMBOK", "exam-prep"]
  students_enrolled INTEGER DEFAULT 0,
  average_rating NUMERIC,           -- 4.9
  total_reviews INTEGER DEFAULT 0,
  pass_rate NUMERIC,                -- 95%
  
  -- Status
  is_active BOOLEAN DEFAULT true,
  published_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Table 2: `ilt_course_cohorts` (Specific Cohort Instances)
```sql
CREATE TABLE ilt_course_cohorts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- Link to course
  course_id UUID NOT NULL REFERENCES ilt_courses(id),
  
  -- Cohort Details
  cohort_name TEXT,                -- "Cohort #1 (Sep 15 Start)"
  start_date DATE NOT NULL,         -- 2026-09-15
  end_date DATE NOT NULL,           -- 2026-10-06
  
  -- Schedule
  session_days TEXT ARRAY,          -- ['Tuesday', 'Thursday']
  session_time_start TIME,          -- 18:00 (6 PM)
  session_time_end TIME,            -- 20:00 (8 PM)
  timezone TEXT,                    -- 'Europe/London'
  
  -- Capacity
  max_students INTEGER,             -- 12
  enrolled_count INTEGER DEFAULT 0, -- 9
  
  -- Instructor
  cohort_instructor_id UUID REFERENCES instructors(id),
  cohort_instructor_name TEXT,      -- Specific for this cohort
  
  -- Status
  status TEXT,                      -- 'open' | 'full' | 'completed'
  enrollment_deadline DATE,         -- 3 days before start
  
  -- Links
  meeting_link TEXT,                -- Zoom/Teams link (populated after start)
  recording_link TEXT,              -- Link to recording after session
  
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Table 3: `ilt_course_enrollments` (Student Enrollment Records)
```sql
CREATE TABLE ilt_course_enrollments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- Link to cohort
  cohort_id UUID NOT NULL REFERENCES ilt_course_cohorts(id),
  course_id UUID NOT NULL REFERENCES ilt_courses(id),
  
  -- Student info
  student_id UUID REFERENCES students(id),
  student_email TEXT NOT NULL,
  student_name TEXT,
  
  -- Enrollment Details
  enrolled_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  status TEXT DEFAULT 'enrolled', -- 'enrolled' | 'completed' | 'dropped'
  
  -- Progress
  sessions_attended INTEGER DEFAULT 0,
  exam_passed BOOLEAN,
  exam_score INTEGER,
  certificate_id UUID,             -- Link to certificate if passed
  
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 📅 SCHEDULE DISPLAY OPTIONS (Research)

### Option 1: Card-Based Cohorts (Current in UX Mockup)
**Pros:** Easy to scan, clear FOMO ("3 seats left"), direct enrollment per cohort  
**Cons:** Doesn't show visual calendar

### Option 2: Interactive Calendar
**Pros:** Visual representation of dates, drag-to-view sessions  
**Cons:** Overkill for 3 cohorts, takes more space

### Option 3: Timeline View
**Pros:** Shows flow: Sep → Oct → Nov, clear progression  
**Cons:** Horizontal scrolling on mobile

### Option 4: Comparison Table
**Pros:** Easy to compare all cohorts side-by-side  
**Cons:** Mobile-unfriendly if many columns

### Recommendation: **Option 1 (Card-Based)** + Inline Calendar
Show cards (Option 1) with a small calendar icon that expands to show all session dates for selected cohort.

**User flow:**
```
Click "View Schedule" on cohort card
  ↓
Show calendar for that cohort (Sep 15 - Oct 6)
  ↓
Highlight Tuesdays & Thursdays
  ↓
Show times: 6-8 PM GMT
  ↓
Show "Add to my calendar" button
```
